## 📑 Contenidos 

</div>

### 🏠 **Página de Inicio**  
- **Sistema de acceso seguro:** Formularios profesionales de [Login y Registro](#) con validación completa y medidor de seguridad para contraseñas.
- **Carrusel interactivo:** Navegación rápida al catálogo y sección "Sobre Nosotros".
- **Secciones destacadas:**  
  - *Hero*: Presentación visual atractiva con imágenes de alta calidad.
  - *Servicios*: Descripción de ventajas y beneficios de la plataforma.
  - *Top Categorías*: Acceso rápido a las categorías principales de productos.

### 📚 **Catálogo de Productos**  
- **Diseño adaptable:** Estilos CSS optimizados para visualización clara en cualquier dispositivo.
- **Filtros intuitivos:** Sistema de filtros por marca y rango de precios.
- **Paginación dinámica:** Navegación entre páginas de productos con indicador visual.
- **Carrito flotante:** Widget que muestra productos seleccionados mientras se navega.
- **Vista rápida:** Modal para ver detalles del producto sin cambiar de página.

### 🛒 **Carrito de Compras**  
- **Sistema completo:** Añadir, eliminar y actualizar cantidad de productos.
- **Persistencia:** Mantiene productos seleccionados durante la navegación.
- **Cálculo automático:** Actualización en tiempo real del subtotal y total.
- **Interfaz intuitiva:** Diseño minimalista y fácil de usar con retroalimentación visual.

### 👤 **Autenticación de Usuario**
- **Inicio de sesión:** Formulario completo con validación de campos.
- **Registro de usuario:** Sistema con verificación de datos y fortaleza de contraseña.
- **Opciones sociales:** Botones para autenticación vía Google y Facebook.
- **Recordatorio:** Opción para guardar credenciales y recuperar contraseña.

### 👥 **Sobre Nosotros**  
- **Página informativa:** Detalles de la misión y valores de la librería.
- **Diseño coherente:** Estilos CSS alineados con la identidad visual del sitio.

## 🚀 Instalación y Uso

</div>

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/samuelbonifacio015/Libreria-JSR.git
   ```

2. **Navega al directorio del proyecto:**
   ```bash
   cd Libreria-JSR
   ```

3. **Abre el archivo index.html en tu navegador:**
   - Doble clic en `index.html` o
   - Usa un servidor local como Live Server en VSCode

4. **¡Explora y disfruta de la aplicación!**
